# HIGH SCHOOL VOLLEYBALL LEGENDS

Tactical volleyball simulation · dream-team builder · Japanese high-school atmosphere.

## Play

Open the GitHub Pages URL after deploy, or:

```bash
npm install
npm run build
npm run preview
```

## Scripts

- `npm run sim` — 5,000-match balance report
- `npm run e2e` — Playwright flow tests
- `npm run gen:players` — regenerate player DB

## Stack

Vite + TypeScript + Preact · Canvas 2D courtside match · pure simulation engine (Node + browser).
